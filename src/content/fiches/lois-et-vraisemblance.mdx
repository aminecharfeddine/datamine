<FicheSection kind="essentiel">
- Bernoulli, binomiale, Poisson, exponentielle, normale, log-normale.
- Choisir selon le type de variable et le mécanisme.
- Poisson : variance = moyenne ; sinon binomiale négative.
- Maximum de vraisemblance : les paramètres qui rendent les données les plus probables.
- Pertes = vraisemblances : MSE (gaussien), MAE (Laplace), log loss (Bernoulli).
</FicheSection>

<FicheSection kind="formules">
$$
\hat\theta = \arg\max_\theta \sum_i \log p(x_i \mid \theta) \qquad P_{\text{Poisson}}(X = k) = \frac{e^{-\lambda}\lambda^k}{k!}
$$

Poisson : $\hat\lambda = \bar x$. $\lambda = 2$ : $P(X = 0) = e^{-2} \approx 0{,}135$.
</FicheSection>
